## سياسة الأمان (بالعربية)

نولي أمان وسلامة مستخدمي **سيل (SAYL)** أولوية قصوى. يلتزم المشروع بمبادئ التصميم الآمن، وتقليل سطح الهجوم، وعدم تخزين أو إرسال أي بيانات حساسة.

### الإصدارات المدعومة

| الإصدار | تلقي التحديثات الأمنية |
|---------|-------------------------|
| 0.1.x   | مدعوم بالكامل           |

### الإبلاغ المسؤول عن الثغرات الأمنية

**يرجى عدم نشر أي تفاصيل عن ثغرة أمنية في تذاكر GitHub Issues العامة حفاظًا على سلامة المستخدمين.**

إذا اكتشفت ثغرة أمنية تمس سلامة سيل أو مكوناته، نرجو الإبلاغ عنها بإحدى الطريقتين:

1. **عبر إشعار الأمان في GitHub (GitHub Security Advisories):**  
   توجه إلى صفحة الأمان في المستودع: `https://github.com/athar-studios/sayl/security/advisories` واضغط على **«Report a vulnerability»**.
2. **عبر البريد المباشر لأثر ستوديو:**  
   أرسل تقريرك إلى: **`security@sayl.site`**

#### المعلومات المطلوبة في البلاغ:
- وصف دقيق وموجز للثغرة.
- خطوات إعادة إنتاج المشكلة أو كود إثبات المفهوم (PoC).
- التأثير المتوقع على النظام أو المستخدم.
- أي اقتراح لمعالجة الخلل إن وُجد.

نتعهد بالرد على البلاغات الأولية خلال 48 ساعة، وموافاتك بجدول الإصلاح قبل نشر التحديث العام.

## Security Policy (in English)

We take the security of **SAYL** users seriously. The project follows secure-by-default architecture, strict bounds checking, and absolute user privacy with zero data transmission.

### Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Fully Supported |

### Reporting a Vulnerability

**Please do not disclose security vulnerabilities publicly via GitHub Issues.**

If you discover a potential vulnerability, please report it privately through:

1. **GitHub Private Vulnerability Reporting:**  
   Navigate to `https://github.com/athar-studios/sayl/security/advisories` and select **'Report a vulnerability'**.
2. **Direct Email:**  
   Email us at: **`security@sayl.site`**

#### What to Include:
- Clear description of the vulnerability.
- Minimal reproducible steps or proof of concept.
- Affected component and potential impact.
- Any suggested fix or remediation.

We acknowledge security reports within 48 hours and work with reporters to verify and resolve issues prior to public disclosure.
