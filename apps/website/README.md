# SAYL Website — Static Download Site

موقع التنزيل الثابت (Static) لمشروع **سيل (SAYL)** — مدير تنزيل Windows مستقل ومفتوح المصدر.

## الهيكل

```
apps/website/
├── index.html      # الصفحة الرئيسية (Arabic RTL + English toggle, accessible)
├── styles.css      # الهوية البصرية، RTL-first، التجاوب، تباين WCAG AA
├── app.js          # تبديل اللغة، قائمة الجوال، عدادات الأداء، أكورديون FAQ
├── favicon.svg     # أيقونة الموقع الرسمية (نسخة من assets/brand/icon.svg)
├── icon-32.png     # أيقونة 32x32 للمتصفحات
├── icon-128.png    # أيقونة 128x128 لأجهزة اللمس
├── og-image.svg    # صورة Open Graph للمشاركة الاجتماعية (1200x630)
└── README.md       # هذا التوثيق
```

## الهوية البصرية (Visual Identity v0.1.0)

- **اللون الأساسي العميق:** النيلي الداكن `#070F2E` كخلفية أساسية للموقع.
- **لون الأقسام والبطاقات المرتفعة:** النيلي المرتفع `#0B1A4E` والبطاقات `#0F2156`.
- **التدرج اللوني للعلامة (Accent Gradient):** `linear-gradient(135deg, #00B6BD, #0B1A4E)` مطبق بدقة على الأزرار الأساسية (`.btn-primary`) والفواصل الجمالية (`.accent-rule`).
- **شعار سيل (SAYL Logo):** أيقونة الشعار الرسمية المعتمدة في رأس الصفحة وفي ذيل الصفحة.
- **معاينة واجهة سطح المكتب (UI Preview):** نموذج حي ودقيق لواجهة التطبيق الحقيقية (مطابق لـ `apps/desktop/src/App.svelte` و `TaskCard.svelte`) مبني بـ HTML و CSS خالصين، وموسوم صراحة بتسمية وصولية واضحة (`معاينة الواجهة`) دون وصفه كلقطة شاشة حقيقية.
- **فاصل أمواج متحرك (CSS Wave Divider):** فاصل بحري انسيابي بلون التركواز `#00B6BD` يعمل بتحريك CSS خالص ويحترم تفضيلات تقليل الحركة (`prefers-reduced-motion`).
- **عدادات الأرقام التقنية:** عدادات للمواصفات الحقيقية (آلة الحالات، الاتصالات المتوازية، أوضاع الاختبار) تتحرك مرة واحدة عند التمرير إليها عبر `IntersectionObserver` مع احترام `prefers-reduced-motion`.

## الخطوط والاعتماديات

- **الخطوط:** مكدس نظام محلي احتياطي (`system-ui, -apple-system, "Segoe UI", "Cairo", "Noto Sans Arabic", Tahoma, sans-serif`)، بدون أي طلبات خارجية أو خطوط CDN.
- **صفر تبعيات خارجية:** لا مكتبات خارجية، لا npm، لا إطارات عمل، لا خطوط ويب بعيدة.

## التجاوب التام (Full Responsiveness)

لا يحدث أي فيضان أفقي (Horizontal Overflow) إطلاقاً عند أي عرض شاشة، وتحديداً عند:
- **1280px:** شاشات سطح المكتب الكاملة مع تخطيط شبكي أنيق وتوزيع متوازن.
- **1024px:** الأجهزة اللوحية الأفقية، مع تحول الشبكات إلى عمودين.
- **768px:** الأجهزة اللوحية والشاشات المتوسطة، حيث يتحول شريط التنقل العلوي تلقائياً إلى زر قائمة حقيقي (`#menu-toggle`) يفتح لوحة تنقل رأسية منسدلة قابلة للوصول، وتتحول جميع الشبكات لعمود واحد.
- **480px / 360px:** الهواتف المحمولة الصغيرة، مع التفاف الكلمات الطويلة والروابط بـ `overflow-wrap: anywhere`، وحجم عنوان مرن عبر `clamp()`.
- **ملاحظة معمارية:** تم تحقيق التجاوب وضبط الفيضان الأفقي بالكامل عبر بنيوية التخطيط (Grid/Flex/Clamp) بدون الاعتماد على `overflow-x: hidden` على وسم `body`.

# التحقق من خلو صفات data-* من وسوم HTML وخلو روابط التنزيل من href="#"
