ادعم استمرار وتطوير سيل

سيل برنامج مجاني، ومفتوح المصدر، وسيبقى دائماً كذلك بلا أي ميزات مدفوعة ولا اشتراكات.

الدعم المالي بأي مبلغ عبر Ko-fi

تطوير البرمجيات المستقلة وصيانتها واختبارها وتوفير شهادات التوقيع الرقمي (EV Code Signing) واستضافة البنية التحتية يتطلب وقتاً وتكاليف سنوية حقيقية. دعمك بأي مبلغ — مهما كان بسيطاً — يساعدنا على التفرغ لتحسين سيل وإضافة الميزات الجديدة ومكافحة شهادات التحذير الزرقاء.

طرق أخرى للمساهمة ودعم المشروع

المساهمة لا تقتصر على الدعم المادي فقط؛ هناك مساهمات تصنع فارقاً حقيقياً معنا:

  • جرّب البرنامج وبلّغ عن الأخطاء: تجربة البرنامج على أنواع مختلفة من الروابط والإبلاغ عن أي خلل عبر GitHub Issues يساعدنا على حل المشاكل فوراً.
  • المساهمة البرمجية: إذا كنت مطوراً تتقن Rust أو Svelte أو TypeScript، يسعدنا استقبال مساهماتك البرمجية بعد مراجعة CONTRIBUTING.md.
  • تحسين الترجمة والنصوص: التدقيق اللغوي والمقترحات النصية تزيد من رقي تجربة المستخدم.
  • انشر الكلمة: شارك سيل مع أصدقائك أو زملائك ممن يبحثون عن مدير تنزيل سريع ونظيف لويندوز.
