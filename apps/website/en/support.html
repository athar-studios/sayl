Support Project Sayl Development

Sayl is free, open source, and will always remain so. No paywalls, no subscriptions.

Financial Contributions via Ko-fi

Developing independent open-source tools, acquiring Windows EV code-signing certificates, running CI/CD test runners, and domain hosting entails ongoing out-of-pocket costs. Supporting us with any amount directly fuels Sayl's future and keeps the software completely free for everyone.

Other Meaningful Ways to Contribute

  • Test and Report Issues: Running Sayl on diverse networks and filing reports on GitHub Issues helps us fix edge cases rapidly.
  • Contribute Code: If you work with Rust, Svelte, or TypeScript, pull requests are warmly welcomed per CONTRIBUTING.md.
  • Improve Phrasing & Translations: Suggest linguistic refinements to ensure an authentic experience in both Arabic and English.
  • Spread the Word: Introduce Sayl to friends and colleagues looking for a clean, fast Windows download manager.
