# دليل توثيق سيل (SAYL Documentation Index)

مرحباً بك في مستودع التوثيق الرسمي لمدير التحميل **سيل (SAYL)** — مدير تحميل مكتوب بلغة Rust وموجّه لنظام Windows أولاً، مع واجهة سطح مكتب Tauri 2 وSvelte 5.

يقدم هذا الفهرس دليلاً شاملاً لكافة وثائق المشروع الفنية والتطبيقية، مع مسارات واضحة ومباشرة تبين من أين تبدأ سواء كنت مستخدماً للتطبيق أو مطوراً مساهماً في بنائه.

---

## مسارات البداية الموصى بها (Start Here)

### للمستخدمين (For Users)
إذا كنت ترغب في استخدام تطبيق سيل على جهازك:
1. ابدأ بقراءة [دليل المستخدم](USER-GUIDE.md) للتعرف على خطوات التثبيت الحالية، وكيفية إضافة رابط تنزيل، ومعاني حالات التنزيل الـ 11، والتعامل مع ملفات `.part`.
2. راجع قسم الأسئلة الشائعة في [دليل المستخدم](USER-GUIDE.md#الأسئلة-الشائعة-faq) لمعرفة حلول مشاكل انقطاع الاتصال ومواقع حفظ الملفات.
3. اطلع على [نموذج الأمان والخصوصية](SECURITY-MODEL.md) للتأكد من التزام التطبيق بعدم جمع أي بيانات أو تحليلات (Zero Telemetry).

### للمطورين والمساهمين (For Contributors)
إذا كنت ترغب في بناء المشروع، تشغيل الاختبارات، أو المساهمة البرمجية:
1. ابدأ بوثيقة [إعداد بيئة البناء](BUILD.md) لمعرفة المتطلبات وسلسلة أدوات GNU المعتمدة محلياً وأوامر الاختبار الموثقة وتجاوز عقبات Windows SDK.
2. اقرأ [المعمارية وتصميم النظام](ARCHITECTURE.md) لفهم تكوين الحزم التسع (`crates`)، آلة الحالات (11 حالة بانتقالاتها الـ 33)، المخزن المقاوم للأعطال، وطبقة HTTP.
3. راجع [الأسئلة الشائعة للمطورين](FAQ.md) لفهم الدوافع الهندسية وراء القرارات التقنية (مثل عدم استخدام SQLite في البداية واعتماد `native-tls`).
4. التزم بضوابط [نموذج الأمان](SECURITY-MODEL.md) لحماية المسارات ورؤوس الطلبات وتجنب التسريبات عبر إعادة التوجيه.
5. راجع [خريطة الطريق](ROADMAP.md) و[سجل التغييرات](CHANGELOG.md) لمعرفة المهام المنجزة وما هو مخطط للتنفيذ تالياً.
