# BOOT-002 — Workspace initialization, Git baseline, and test harness setup

state: todo
scope: تهيئة مستودع Git محلي نظيف، إعداد ملفات الحالة وهيكل المشروع الأساسي، وتجهيز اختبارات البنية التحتية المحلية.
لا تنشئ محركًا أو واجهة وهمية في هذه المهمة؛ يقتصر العمل على البنية التحتية والبيئة.

## القبول
1. إنشاء مستودع Git محلي بتهيئة مصرح بها رسميًا من مالك المشروع، وتأسيس أول commit مرجعي للحزمة الأساسية.
2. التحقق من نظافة شجرة العمل (`git status --porcelain` فارغ) واستخراج `source_commit` و `source_tree` صالحين.
3. مراجعة وتحديث `.gitignore` لضمان استبعاد مسارات الأدلة والتقارير والملفات المؤقتة (`reports/`, `artifacts/`, `target/`, `node_modules/`) لضمان الحفاظ على snapshot نظيف.
4. إعداد هيكل المجلدات الأولي وفق معمارية المشروع المعتمدة في `docs/MASTER-PLAN.md` (§4).
5. التحقق من توفر بيئة Rust و أدوات البناء التجميعية الضرورية وتوثيقها بدقة، وتوفير fixtures للاختبارات الحتمية (deterministic fixtures).
6. تشغيل أوامر التحقق وسير العمل: `validate` و `preflight` بنجاح (exit code 0).
7. إعداد تقرير builder للمهمة `reports/BOOT-002/builder.json` مربوط بالـ Git snapshot النظيف.
8. تحديث `STATUS.json` و `docs/agent/HANDOFF.md` بالخطوات المنجزة والمخاطر المتبقية.

## أدلة
- سجلات `git log -1` و `git status --porcelain`.
- سجلات فحص وتوفر الأدوات وملفات البيئة في `artifacts/BOOT-002/`.
- سجلات تنفيذ `validate` و `preflight` و `check-report` مع exit code 0.

## التفويض
- تنفيذ محلي فقط داخل نطاق تهيئة البيئة والـ baseline.
- ممنوع أي push إلى مستودعات بعيدة أو تعديل مواصفات المهام خارج التفويض.
- لا تنزيل حزم أو أدوات خارجية تتطلب مصاريف أو أذونات موسعة دون موافقة مسبقة.
