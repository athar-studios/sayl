# خطة إصدارات سيل (SAYL Release Planning)

تحدد هذه الوثيقة خريطة الإصدارات المجدولة لمشروع **سيل (SAYL)** — مدير التنزيل لنظام Windows ومحركه المكتوب بلغة Rust. يوضح الجدول التالي نطاق كل إصدار وحالته الواقعية والاعتماديات بين الإصدارات المتعاقبة، مع روابط الخطط التفصيلية.

---

## جدول الإصدارات (Release Matrix)

| الإصدار (Version) | التركيز الأساسي (Focus) | الحالة (Status) | الاعتمادية على الإصدار السابق (Dependency) | رابط خطة الإصدار (Plan Link) |
|---|---|---|---|---|
| **`v0.1.0`** | النواة الأساسية ومحرك HTTP المتوازي، استئناف آمن بالتحقق، مخزن مهام مقاوم للتعطل بنمط WAL، واجهة سطر الأوامر sayl CLI، واجهة سطح المكتب Tauri 2 (Windows)، وتكامل ملحق Chromium/Edge عبر Native Messaging ومثبتات أولية. | قيد التطوير (غير مطلق / In Progress) | لا يوجد (الإصدار التأسيسي لنظام Windows) | [وثيقة المخطط العام](../MASTER-PLAN.md) / [سجل التغييرات](../CHANGELOG.md#010) |
| **`v0.2.0`** | تنزيل الفيديو والوسائط المتعددة عبر تكامل أدوات `yt-dlp` و `FFmpeg`، استخراج البيانات الوصفية، دمج المسارات، وعزل أخطاء قوائم التشغيل (Playlists). | لم يبدأ (Not Started) | يعتمد على استقرار محرك وتنسيق مهام v0.1.0 وإدارة العمليات وواجهة سطح المكتب. | [v0.2.0/PLAN.md](v0.2.0/PLAN.md) |
| **`v0.3.0`** | دعم ملحق متصفح Firefox عبر Gecko ومطابقة Native Messaging، جدولة التنزيلات الزمنية (Time Scheduling)، وتحديد سقوف السرعة (Speed Limits) من واجهة المستخدم. | لم يبدأ (Not Started) | يعتمد على جسر Native Messaging ومحرك الجدولة والواجهة في v0.1.0 وv0.2.0. | [v0.3.0/PLAN.md](v0.3.0/PLAN.md) |
| **`v0.4.0`** | دعم بروتوكول التورنت وروابط المغناطيس (Magnet Links) عبر تكامل `librqbit`، وإدارة السرب الخاضع للتحكم، واستثناء الملفات وحفظ الحالة والبث المباشر المرجعي. | لم يبدأ (Not Started) | يعتمد على استقرار مخزن المهام وإدارة الموارد والتخزين في v0.1.0. | [v0.4.0/PLAN.md](v0.4.0/PLAN.md) |
| **`v0.5.0`** | بيئة تشغيل الإضافات المعزولة بـ WASM (Wasmtime)، وسيط الأذونات وحدود الوقود والموارد، وكتالوج الإضافات والثيمات في التطبيق والموقع. | لم يبدأ (Not Started) | يعتمد على استقرار واجهات البرمجة والمحرك ونظام الثيمات في الإصدارات السابقة. | [v0.5.0/PLAN.md](v0.5.0/PLAN.md) |
| **`v1.0.0`** | دعم منصة نظام أندرويد (UniFFI + Kotlin + SAF)، التوقيع الرقمي للمثبتات بشهادة معتمدة (EV)، ونظام التحديث التلقائي الآمن مع الحماية ضد التراجع (Rollback Protection). | لم يبدأ (Not Started) | يعتمد على اكتمال ونضج كافة مكونات النظام من v0.1.0 إلى v0.5.0 والتدقيق الأمني المستقل. | [v1.0.0/PLAN.md](v1.0.0/PLAN.md) |

## هيكل مجلدات الإصدارات

يحتوي مجلد كل إصدار على ملفين أساسيين:
- `PLAN.md`: يحدد النطاق التفصيلي، قائمة المهام بأرقامها وأوصافها، شروط القبول الصارمة، الاختبارات المطلوبة، والاعتماديات.
- `STATUS.md`: يسجل الحالة الواقعية الصادقة لكل مهمة، وتاريخ آخر تحديث، والنتائج المسجلة فعلياً.
