# خطة إصدار سيل v1.0.0 (SAYL v1.0.0 Release Plan)

## 1. النطاق (Scope)

يمثل هذا الإصدار مرحلة النضج الشامل والإطلاق العام الرئيسي لمشروع سيل (SAYL). يشمل النطاق:
1. توسيع نطاق البرنامج ليشمل نظام التشغيل أندرويد (Android 14+) عبر جسر UniFFI للنواة المشتركة مع واجهة مستخدم أصلية بلغة Kotlin، ودعم خدمات التنزيل في الخلفية وإطار عمل الوصول للتخزين (Storage Access Framework - SAF) والإشعارات الحية.
2. توفير حزم التثبيت الرسمية لنظام Windows الموقعة برمجياً بشهادة مطور معتمدة (EV Code Signing) لإزالة تحذيرات SmartScreen نهائياً.
3. بناء نظام تحديث تلقائي مشفر وآمن يعتمد على تواقيع رقمية مستقلة ويوفر حماية صارمة ضد هجمات التراجع (Rollback Protection) والعبث.
4. التحقق التام من نزاهة مسار البناء (Source-to-Artifact Integrity) ومطابقة بصمات SHA-256 للملفات على الموقع الرسمي ومستودع GitHub قبل الإطلاق العام بموافقة المالك.

---

## 2. المهام بأرقامها (Tasks)

| رقم المهمة (Task ID) | الوصف بسطر واحد (One-Line Description) |
|---|---|
| **`AND-001`** | دراسة تجريبية (Spike) لجسر UniFFI والخدمات الخلفية والتخزين عبر أجهزة أندرويد حقيقية. |
| **`AND-002`** | تطوير واجهة أندرويد التفاعلية بلغة Kotlin مع دعم تنزيل HTTP وإشعارات النظام وإطار عمل SAF. |
| **`REL-002`** | بناء نظام التحديث التلقائي الموقع رقمياً مع آليات كشف العبث والحماية الصارمة من التراجع (Rollback Protection). |
| **`REL-003`** | التحقق الآلي من سلامة مسار إنتاج الحزم (Source-to-Artifact) ونزاهة روابط وبصمات SHA-256 على الموقع الرسمي. |
| **`REL-004`** | مراجعة واعتماد قرار الإطلاق العام الرسمي v1.0.0 بالتنسيق والموافقة الصريحة لمالك المشروع. |

## 3. شروط القبول (Acceptance Criteria)

- **استقرار أندرويد على أجهزة حقيقية:** تشغيل محرك سيل عبر UniFFI على أجهزة أندرويد فعلية بنظام Android 14+، والتكامل مع إطار عمل التخزين (SAF) لاختيار مجلد التنزيل دون الحاجة لأذونات جذرية.
- **إدارة الخلفية وانقطاع النظام في أندرويد:** استخدام Foreground Services بإشعار ثابت أثناء التنزيل النشط، وحفظ نقاط الاستئناف دورياً، وضمان استعادة المهام بنجاح بعد إطفاء الشاشة أو تبديل الشبكة (مع توضيح القيود في حال الإيقاف الإجباري Force Stop).
- **التوقيع الرقمي للمثبتات (Windows EV Signing):** توقيع حزم التثبيت (NSIS / MSI) والملفات التنفيذية بشهادة توقيع كود معتمدة، والتأكد من تثبيتها على أجهزة Windows نظيفة دون ظهور تحذيرات SmartScreen أو حظر مكافحات الفيروسات.
- **تحديثات موثقة ومحمية من التراجع:** لا يُقبل أي تحديث تلقائي إلا بعد التحقق من صحة التوقيع الرقمي بالمفتاح العام المعزول المخصص للتحديثات؛ ورفض أي حزمة تحمل إصداراً أقدم من الإصدار الحالي لحماية المستخدم من ثغرات الرجوع (Rollback Attacks).
- **نزاهة مسار البناء والموقع (Reproducibility & Integrity):** مطابقة بصمات التجزئة في ملف `SHA256SUMS.txt` مع الملفات المرفوعة على الموقع الرسمي ومستودع GitHub، وخلو مسارات البناء وسجلات الإصدار من أي أسرار أو عناوين خاصة.
- **موافقة المالك الصريحة:** لا يتم نشر أو إعلان الإصدار العام رسمياً إلا بعد استيفاء جميع تقارير الاختبارات والمراجعات الأمنية وبموافقة كتابية معتمدة من مالك المشروع.

## 4. الاختبارات المطلوبة (Required Tests)

1. **اختبارات دورة حياة أندرويد الحقيقية (Android Real-Device Lifecycle Tests):** اختبارات على أجهزة فعلية تشمل سيناريوهات إطفاء الشاشة، وانقطاع شبكة Wi-Fi والتحويل إلى شبكة الجوال، وإزالة التطبيق من قائمة التطبيقات الحديثة (Swipe from Recents).
2. **اختبارات جسر FFI ونقاء الذاكرة (UniFFI Memory Safety Tests):** اختبار تمرير البيانات الكثيفة بين Rust وKotlin ومراقبة مؤشرات الذاكرة للتأكد من عدم وجود أي تسريب للذاكرة (Memory Leaks).
3. **اختبارات أمان التحديث التلقائي (Updater Tamper & Rollback Tests):** محاكاة محاولة تحديث بحزمة معدلة البايتات، ومحاولة تحديث بحزمة سليمة ولكن برقم إصدار قديم، والتأكد من فشل التحديث وحظر التثبيت في الحالتين.
4. **اختبارات التثبيت والإلغاء النظيف (Clean Install/Upgrade/Uninstall Tests):** اختبار مثبتات Windows وAPK على بيئات نظيفة خالية من أي إعدادات مسبقة، والتأكد من إمكانية الترقية السلسة وإلغاء التثبيت التام.
5. **اختبارات مطابقة البصمات (Release Hash Integrity Verification):** فحص آلي لمطابقة بصمات SHA-256 للملفات المبنية مع الملفات المرفوعة وروابط الموقع الرسمي `sayl.site`.

---

## 5. ما يعتمد عليه من الإصدار السابق (Dependency on Previous Release)

يعتمد هذا الإصدار على:
- استقرار ونضج كامل مكتبات النواة ومحركات التنزيل والتخزين والوسائط والتورنت والإضافات المنجزة في الإصدارات من `v0.1.0` إلى `v0.5.0`.
- اجتياز مراجعة الأمان المستقلة والتدقيق الشامل لأسطح الهجوم (`SEC-STRIX-001`).
- التحقق المكتمل لسياسة الخصوصية والتدقيق الشبكي للبيانات (`PRIV-001`).
- البنية التحتية لموقع التنزيل الثابت (`apps/website`).
