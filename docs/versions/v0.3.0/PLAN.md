# خطة إصدار سيل v0.3.0 (SAYL v0.3.0 Release Plan)

## 1. النطاق (Scope)

يركز هذا الإصدار على توسيع نطاق التقاط التنزيلات وإدارة طابور التنزيل الذكي عبر ثلاثة محاور أساسية:
1. دعم ملحق متصفح Firefox عبر حزمة متوافقة مع متطلبات Mozilla WebExtensions ومطابقة لعقد Native Messaging الآمن المطور لمتصفحات Chromium.
2. توفير نظام الجدولة الزمنية (Time Scheduling) المتقدم، والذي يتيح للمستخدم تحديد أوقات محددة لبدء المهام أو إيقافها، مع التعامل الدقيق مع المناطق الزمنية وإعادة تشغيل النظام.
3. توفير آلية التحكم في حدود وسقوف السرعة (Speed Limits / Bandwidth Throttling) مباشرة وبشكل حي من واجهة المستخدم لضبط استهلاك سرعة الإنترنت لكل مهمة وإجمالياً.

---

## 2. المهام بأرقامها (Tasks)

| رقم المهمة (Task ID) | الوصف بسطر واحد (One-Line Description) |
|---|---|
| **`WEB-003`** | بناء حزمة ملحق متصفح Firefox واختبار تكاملها مع مضيف Native Messaging المحلي على Windows. |
| **`QUEUE-001`** | تطوير نظام الجدولة الزمنية للمهام (وقت البدء، نافذة التنزيل، أيام الأسبوع، واستعادة الجدولة بعد إعادة التشغيل). |
| **`LIMIT-001`** | دعم تحديد وتعديل سقوف سرعة التنزيل ديناميكياً من واجهة المستخدم الفردية والإجمالية (Bandwidth Throttling). |

---

## 3. شروط القبول (Acceptance Criteria)

- **توافق ملحق Firefox:** إنشاء حزمة ملحق Firefox متوافقة مع Manifest V3 / Gecko ومسجلة لمضيف Native Messaging في سجل Windows (`HKEY_CURRENT_USER\Software\Mozilla\NativeMessagingHosts`) مع استيفاء قيود الأمان وعدم تسريب أي معلومات تصفح للمواقع غير المصرح بها.
- **التقاط التنزيلات الآمن:** دعم التقاط التنزيلات اليدوي والتلقائي عبر ملحق Firefox مع إرسال روابط التنزيل وترويسات `Cookie` و `Referer` المعتمدة بأمان إلى تطبيق سيل المحلي.
- **جدولة زمنية دقيقة ومستدامة:** إمكانية تحديد موعد بدء تنزيل مستقبلي (مثال: في أوقات الفجر أو خارج ساعات الذروة) مع حفظ مواعيد الجدولة في السجل الدائم، بحيث تستمر الجدولة دون فقدان إذا تم إغلاق البرنامج وإعادة فتحه قبل حلول الموعد.
- **معالجة المناطق الزمنية والتوقيت الصيفي:** دعم حساب الفروق الزمنية وتغييرات التوقيت الصيفي (DST) بدقة لمنع تشغيل المهام في غير موعدها المحدد.
- **تحديد السرعة الحي (Dynamic Speed Limiting):** تطبيق خوارزمية تنظيم التدفق (Token Bucket Rate Limiter) في عميل HTTP لضبط سقف سرعة التنزيل (بالكيلوبايت أو الميجابايت في الثانية) وتأثيره الفوري على المهمة الجارية دون الحاجة لإعادة تشغيلها، مع إمكانية تحديد سقف شامل للتطبيق وسقوف للمهام المنفردة.

## 4. الاختبارات المطلوبة (Required Tests)

1. **اختبارات ملحق Firefox (Extension Integration Tests):** اختبار تشغيل ملحق Firefox داخل بيئة اختبار آلية والتحقق من تبادل رسائل Native Messaging بنجاح مع مضيف سيل.
2. **اختبارات الجدولة الزمنية (Scheduler Unit Tests):** اختبارات وحدة لمحرك الجدولة الزمنية للتحقق من إطلاق المهام في التوقيت المحدد بدقة والتعامل مع حالات تأخر استيقاظ النظام أو تجاوز وقت البداية.
3. **اختبارات حفظ واستعادة الجدولة بعد التعطل (Scheduler Persistence Tests):** التأكد من بقاء المهام المجدولة واستئناف تتبع مواعيدها بعد محاكاة إغلاق مفاجئ للتطبيق.
4. **اختبارات خوارزمية تقييد السرعة (Throttling Benchmarks):** قياس دقة محدد السرعة ومقارنة سرعة التدفق المقاسة فعلياً بالقيمة المدخلة في واجهة المستخدم بنسبة خطأ لا تتجاوز 5%.
5. **اختبارات استجابة واجهة المستخدم (UI Responsiveness Tests):** التأكد من عدم تجميد أو تأخير واجهة سطح المكتب عند تعديل سقوف السرعة أثناء نقل كميات ضخمة من البيانات.

---

## 5. ما يعتمد عليه من الإصدار السابق (Dependency on Previous Release)

يعتمد هذا الإصدار على:
- بنية مضيف Native Messaging التي تم تأسيسها لملحق متصفحات Chromium في `v0.1.0`.
- محرك النقل وعميل الشبكة `sayl-http` المكتمل في `v0.1.0` لتطبيق خوارزمية حدود السرعة.
- مخزن المهام `sayl-storage` لحفظ سجلات الجدولة الزمنية وتكوينات حدود السرعة.
- واجهة سطح المكتب Tauri 2 لإضافة عناصر التحكم في الجدولة والسرعة.
