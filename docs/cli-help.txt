$ sayl --version

$ sayl --help
SAYL (سيل) - High-performance Windows-first download manager

Usage: sayl.exe [OPTIONS] <COMMAND>

Commands:
  add      Add one or more URLs to the download queue
  start    Start one or all queued download tasks
  list     List all download tasks in tabular or JSON format
  info     Display detailed information about a specific task
  pause    Pause an active or queued download task
  cancel   Cancel an active or queued download task
  remove   Remove a download task from storage
  recover  Recover non-terminal tasks interrupted by crash or restart
  events   Stream live engine events as JSON until interrupted
  help     Print this message or the help of the given subcommand(s)

Options:
      --download-dir <DOWNLOAD_DIR>  Download destination directory [default: %USERPROFILE%\\Downloads\\SAYL]
      --data-dir <DATA_DIR>          Data and storage directory [default: <download-dir>\\.data]
      --connections <CONNECTIONS>    Maximum concurrent connections per task (used for parallel ranged downloads)
      --concurrent <CONCURRENT>      Maximum concurrent active download tasks
      --json                         Output results in JSON format
  -q, --quiet                        Suppress progress and informational output
  -v, --verbose                      Enable verbose diagnostic logging
      --lang <LANG>                  Output language [default: ar] [default: ar] [possible values: ar, en]
  -h, --help                         Print help
  -V, --version                      Print version

Exit codes:
  0  Success
  2  Usage error
  3  Task failed
  4  Cancelled
  5  Store or I/O error
